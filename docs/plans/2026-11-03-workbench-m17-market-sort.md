# 工作台 M17（市场排序与分类）

> 2026-11-03。市场补充标签筛选和排序，方便在技能/插件条目变多后浏览。

## 已完成

### 后端

- `GET /api/market` 新增：
  - `tag`：精确标签过滤；
  - `sort=rating|name|source`：按评分（默认）、名称、来源排序；
  - 返回全量 `tags`，供前端筛选器使用。
- 搜索 `q` 与 `tag` 可组合。

### 前端

- 市场顶部新增排序下拉：按评分 / 按名称 / 按来源；
- 标签 chips：全部 + 所有标签，点击筛选；
- 搜索、标签、排序都会重新请求市场。

## 验证

- `npm run typecheck`、`npm run build` 通过；
- `tests/test_market.py` 新增：`tag=研究` 返回两条研究技能、`sort=name` 名称有序、响应含标签集合；
- 非 Docker 全量：见最终报告；
- Playwright：5 个标签、选中“研究”后 1 条，无 console 报错。

## 边界

- 标签是精确匹配，不支持多选/排除；
- 排序只在当前结果内做，不跨页；
- 没有分页/分类树/搜索历史。
