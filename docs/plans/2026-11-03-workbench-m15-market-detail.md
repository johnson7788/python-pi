# 工作台 M15（市场搜索与详情）

> 2026-11-03。技能/插件市场支持关键词搜索和条目详情，详情展示来源、作者、标签、评分与 SKILL/README。

## 已完成

### 后端

- `GET /api/market` 增加 `q` 参数：按名称、描述、作者、来源、标签做大小写不敏感子串匹配；
- 新增 `GET /api/market/{kind}/{id}`：
  - 返回条目元数据、安装状态、评分；
  - 技能返回 `SKILL.md` 内容；插件读取包内 `README.md`；
  - 未知条目 404。
- `market.py` 增加 `search_items()`、`readme_for()`；
- 示例插件补了 `README.md`。

### 前端

- 市场顶部新增搜索框，输入即按 `q` 过滤；
- 卡片新增「详情」入口；
- 详情弹窗显示：名称、来源、版本、作者、标签、评分、SKILL/README 原文；
- 详情内可直接安装（已安装/无权限时禁用）。

## 验证

- `npm run typecheck`、`npm run build` 通过；
- `tests/test_market.py` 新增用例：`q=证据` 只返回证据表、`q=社区` 返回两条社区技能、详情包含 SKILL 内容、未知条目 404；
- 非 Docker 全量：**642 passed**；
- Playwright：搜索“证据”后 1 条、打开详情显示 SKILL 内容，无 console 报错。

## 已知边界

- 只是子串搜索，没有分词/排序/分页/分类筛选；
- 详情是原始 Markdown 文本，没有渲染、截图、版本历史；
- 没有评论、评分审核、防刷；
- 插件详情只读包内 README，不会执行插件代码。
