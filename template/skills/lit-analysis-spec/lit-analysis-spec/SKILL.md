# 文献分析 · 交付契约

读者拿这份报告去选题、写综述、选刊。他要的是**数字可信、维度诚实、能追到查询**。

四条硬规矩，违反任何一条都算没做完：

1. **先体检再出图**：任何报告/结论之前先 `lit_probe`，拿到命中数与字段覆盖率；
2. **覆盖率 < 30% 的维度不画**，报告里写成一句话说明，不许用别的库的数据补齐；
3. **每个数字带分母和口径**：命中 8,538 篇里的 845 篇，不是“很多”；
4. **抽样必须标样本量**：国家/机构、关键词、作者、共被引都是抽样，图上写不下就写在图注里。

## 一、顺序固定

```
lit_probe  →  （lit_aggregate / lit_entities / lit_similar 按需）  →  lit_report  →  对话里 3 条结论
```

- **probe** 给出 `cohort_n` 与各维度覆盖率。命中为 0 或极小时，先收窄/放宽检索式，再谈分析。
- **aggregate** 一次一个维度，返回 Top-N + 分母。不要自己把两个维度的数字相乘。
- **report** 生成 Word；它内部复用同一套聚合，报告里的数不该与 aggregate 返回的有差异。
- 报告有 `depth`：`full`（17 节 24 图，默认）/ `brief`（8 图，快）。用户没特别说就用 full。

## 二、本库的数据现实（2026-11 实测）

| 维度 | 字段 | 典型覆盖 | 口径 |
|---|---|---|---|
| 年度 | `doc_publish_time` | 100% | 全量聚合 |
| **国家/机构** | `doc_first_addr` / `doc_addr`（解析） | 98.6% 有地址，**解析成功 ~86–90%** | 抽样 5,000 篇，城市/州/缩写词典兜底 |
| 期刊 | `doc_source_journal` | 高 | 全量聚合 |
| 影响因子 | `doc_if` | ~91% | 均值可横向比，不能当质量结论 |
| JCR / 中科院分区 | `jcr_area` / `zky_area` | ~70% / ~95% | Q1–Q4、医学 1 区 |
| 研究类型 | `is_basic_research` | **41%** | 只能看趋势，不能当精确占比 |
| 文献类型 | `doc_publish_type` | ~63% | Review / Case Reports / RCT |
| 作者 | `doc_author_nested.name` | ~92% | **未消歧**，同名合并 |
| 作者关键词 | `doc_keywords` | ~62% | 整串存储，抽样切分，上限 10,000 篇 |
| MeSH | `doc_mesh_terms_query` | ~69% | 不要用 `mesh_tags`（<1%） |
| UMLS 实体 | `doc_abstract_umls_nested` | ~87% | 必须过滤 `similarity==1.0` |
| 疾病分类 | `illness` | ~40–56% | 中文分类，`$$` 多标签要拆开合并 |
| 共被引 | `reference_doc_nested` | 62% | **样本内**可算共被引，没有被引文献元数据 |
| 被引 | `cited_by` | ~66% | 不同年份不可直接比 |
| 中国省份 | 地址解析 + 城市词典 | 中国样本的 ~92% | 识别不出记“未识别”，不硬猜 |
| 中文文献 | `cn_document_all_data_data_dept_v2` | 1700 万条 | **独立口径**，不与英文库相加 |

**不能下的结论**（说了就是编）：

- GO/KEGG 富集——UMLS 实体不是基因 symbol；
- 蛋白互作（PPI）——没有互作数据，实体共现只能叫“共同被讨论”；
- CiteSpace 期刊双图叠加——没有 WoS 学科基底图；
- 关键词 burst——报告里的“新兴主题”是早期/近期出现率之差，**不是** Kleinberg burst；
- “某某团队领先”“某国主导”这类判断。

## 二·五、中文库与对比

中文库是另一套语料（1700 万条，标题/摘要/关键词/基金/机构），口径与英文库完全不同：

- 检索走 `doc_title` 的 **OR** 分词（ik 分词器），同义词要自己写全；
- 只做补充视角，**命中数不能与英文库相加或折算**，报告里单独成节；
- `doc_institution` 常常只填到城市，已归入“省份/地区”，不要当机构排名用；
- 基金字段混着模板文字，工具已过滤（含“邮箱/Email/Foundation”的丢掉）。

主题对比（`lit_compare`）用的是同一套指标：发文量、近三年占比、近年增速、平均 IF、Q1 占比、
国家多样性、主题集中度。雷达图按两组最大值归一，只能看**形状差异**；绝对数值看返回的表。
两组命中数不能相加。

## 三、检索式写法

- 词用空格分隔，按 **AND** 处理：`lung cancer immunotherapy`；
- 默认检索**标题**（`field=title`）；要覆盖综述类内容用 `title_abstract`（命中约 5 倍）；
- 同义词不会自动扩展：`nsclc` 与 `non-small cell lung cancer` 是两个词；
- 命中 >10 万先收窄：加限定词、缩时间窗、改回 title；
- 命中 <200 先放宽：改 `title_abstract`、扩时间窗。

## 四、口径怎么报

每份交付至少写清：**索引（`document_v4`）、检索字段、检索式、时间窗、命中数**，
再加一句哪些维度是抽样。报告页脚已自动带上；对话里也要说一句。

## 五、常见退化与处置

| 现象 | 处置 |
|---|---|
| 国家解析率 < 70% | 报告里写清解析率，并且不要用它做“主导地位”判断 |
| 某个网络图出不来（边太少） | 说“样本内共现不足”，不要改口径硬画 |
| 关键词样本 < 3000 | 提高样本量重跑（上限 10000），或改用 MeSH |
| 作者榜出现同名合并 | 注明“未消歧”，不要点名评价个人 |
| 机构榜里同一家出现两次 | 工具已按 token 包含度归并；仍有残留时在报告里说明“未完全归并” |
| 两组对比指标一边倒 | 先看量级差，量级差 5 倍以上时雷达图意义不大，直接讲数字 |
| 命中年份跨度 < 3 年 | 不做趋势判断，只说存量结构 |
| 报告里出现模型自己写的数字 | 删掉，改用工具返回的值 |
