# 文献计量报告 · 交付契约

产物是一份**能直接发出去的 Word**：17 节、最多 24 图、4 表。读者可能不懂文献计量，但他会看数字对不对。

## 一、调用

```
lit_report(query="...", title="...", field="title_abstract",
           date_from="2012-01-01", date_to="2022-12-31",
           depth="full",            # full = 18 节 37 图；brief = 8 图
           include_cn=True, cn_terms="肺癌 免疫治疗")   # 可选：中文库补充
```

返回：Word 路径、Markdown 路径、图片目录、bundle id。**不要**把报告正文复制回对话，
对话里只给结论、路径和口径。

## 三、断图规则

工具按覆盖率决定是否出图，你在对话里解释时也要保持一致：

- 国家/机构覆盖率 < 30% → 第 4 节只留一段说明，没有图；
- 疾病谱 < 30% → 第 12 节只留说明；
- 网络图节点太少 → 不生成，正文不会出现该图；
- 关键词、MeSH、共被引都是抽样，图注里有样本量。

## 四、结论怎么写

每条结论 = **一个数字 + 一个判断 + 一个动作**。

- 好：`2021 年发文 2,106 篇，是 2012 年（88 篇）的 24 倍；领域处于扩张期，适合切入新靶点。`
- 坏：`该领域蓬勃发展，前景广阔。`

禁止：

- 把“发文多”说成“水平高”；
- 用影响因子给单篇文献或作者下质量结论；
- 跨年比较被引次数；
- 把抽样比例当全量比例；
- 把“实体共现”说成“蛋白互作”。

## 四·五、导出 PDF / PPT

同一个报告目录可以再导出两种格式，不必重新算数：

```
lit_export(path="<report.docx 或报告目录>", format="pdf" | "pptx" | "both")
```

- PDF 优先走 LibreOffice（`soffice`）；没有 soffice 时自动退回内置渲染器（一图一页，版式朴素但可发），
  返回里会注明用了哪条路径；
- PPT 是“一图一页”：标题页 + 摘要页 + 每张图一页（图题 + 图注），适合直接讲。

## 五、交付话术

```
报告已生成：8,538 篇，24 张图。
Word：<路径>
口径：infoxmed document_v4 / 标题+摘要 / <检索式> / <时间窗>
三句话：①… ②… ③…
局限：国家/机构为地址解析（样本 5,000，解析率 90%）；关键词、作者、共被引为抽样；
      GO/KEGG 与 PPI 本库不支持。
```

## 六、不说谎检查表（交付前逐条过）

- [ ] 报告里的每个数字都能在工具返回或 bundle 里找到；
- [ ] 没有出现 GO/KEGG/PPI/双图叠加的图或排名；
- [ ] 抽样结论写明了样本量（国家、关键词、作者、共被引）；
- [ ] 作者榜标注了“未消歧”；
- [ ] “新兴主题”没有被说成 burst；
- [ ] 页脚有索引、检索式、时间窗、生成时间；
- [ ] 对话里的三句话与报告正文不矛盾。
